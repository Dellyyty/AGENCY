# AGENCY

A dark, premium, single-page landing for an AI-powered web design studio. Editorial typography, liquid glass effects, cinematic video backgrounds.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS 3
- motion (Framer Motion successor)
- hls.js for Mux HLS video backgrounds
- lucide-react icons

## Services highlighted

- Web Design (AI-assisted)
- Web Development
- Branding & Identity
- Conversion Optimization
- Performance & SEO
- Ongoing Optimization

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
